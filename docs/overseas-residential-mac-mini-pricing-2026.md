## 四、Mac mini M4（16GB + 256GB）并发 Claude Code 与本地 MCP 实测边界

1. **为何 16GB 通常够用**：Claude Code 的上下文推理完全运行在 Anthropic 云端，本地内存消耗集中在 IDE、终端与 Docker 容器。
2. **稳定负载参考**：同时开启 **2–3 个前后端工程** 的 Claude Code 并行会话 + **3–5 个轻量级 Node/Python MCP Server** + 常规调试浏览器，实测可流畅长期驻留。
3. **调优建议**：用 **OrbStack** 替代传统 Docker Desktop 可节省约 2–3GB 常驻内存；单元测试优先使用 SQLite 或按需启停容器，不在本地运行开源大模型。只有常驻多套重型微服务容器或频繁大规模移动端编译时，再加 ¥400/月选 M6。

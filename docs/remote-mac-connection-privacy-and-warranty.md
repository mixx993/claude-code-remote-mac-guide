## 二、为什么原生家宽托管池严禁私装穿透与恶意爬虫？

如果是自己买断放置在海外亲友家中的私人 Mac mini，自行配置 `Tailscale` 或远程命令行直连完全取决于个人习惯。但在服务多位开发者的合规原生家宽托管池里，**LikeCC (`likecc.app`)** 执行严格红线以保住池内住宅 IP 的长期纯净：

1. 严禁搭建代理、翻墙节点、VPN 或将本机充当其他设备/服务器的网络出口；
2. 严禁运行 `one-api`、`new-api`、`Sub2API`、`CLIProxyAPI` 等任何将订阅转为 API 的中转或拼车程序；
3. **严禁恶意爬虫、高频批量抓取、端口扫描、撞库刷量或引发上游 ISP Abuse 投诉的行为**；
4. 严禁私自安装 `Tailscale`、`ZeroTier`、`frp`、`cloudflared`、`ngrok` 等穿透工具及未报备第三方远控（正常多项目并行、OrbStack 容器与本地 Web / API / MCP 调试完全不受限）。

## 三、远程物理 Mac 代码与密钥隐私 5 条实操

1. **物理单租户独占与先验机**：每台 M4 / M6（16GB+256GB）均为一客一机一系统盘独占，不与他人共用系统桌面；默认不扫描客户源码，仅在主动协助或安全异常核查时按规接入。
2. **用仓库级细粒度 Git 访问令牌（Fine-Grained PAT）拉代码**：在 GitHub / GitLab 为当前项目生成限定仓库范围与有效期的 HTTPS 细粒度访问令牌（Fine-Grained PAT），项目交接或退租时一键吊销即可切断访问。
3. **生产库凭证与个人主密码不落开发机**：远端 `.env` 仅放置测试库与脱敏示例配置，生产数据库根凭证、网银与个人主邮箱密码请勿保存在远端桌面或浏览器。
4. **个人与 Claude Team 登录端隔离**：个人协助号限单人在租用 Mac 内使用；Claude Team 多席位共机时，高级号用机内 Claude 客户端、标准号用 Chrome 独立个人资料（Profile），为标准号另租独立 Mac 时也可在该专属机器直接登客户端。
5. **到期前提醒与 24h 导出机制**：到期前 3 天团队提醒备份；未续费保留 24 小时免费临时导出宽限期，期满系统清理重置。同时注意本地盘清理与 Anthropic 云端对话历史删除属于不同操作。
